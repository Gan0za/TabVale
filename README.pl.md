Rozszerzenie do Chrome i Microsoft Edge, które zastępuje stronę nowej karty
konfigurowalnym pulpitem: wyszukiwanie, wiele ekranów zakładek i tła.

## Funkcje

- Wyszukiwanie z wyborem wyszukiwarki; lista jest edytowalna.
- Wiele ekranów zakładek: przełączanie kropkami, przesunięciem na pustym
  obszarze i `Alt+←/→`.
- Zakładki z ikonami i sortowaniem przeciąganiem; przenoszenie między ekranami.
- Tła: URL, plik lokalny, kolor lub gradient.
- Motywy (automatyczny/jasny/ciemny) i 13 języków interfejsu.
- Import i eksport ustawień w JSON.

## Instalacja

1. Otwórz `chrome://extensions` lub `edge://extensions`.
2. Włącz tryb programisty.
3. Kliknij „Załaduj rozpakowane” i wybierz katalog główny projektu.
4. Otwórz nową kartę.
