Chrome 및 Microsoft Edge용 확장 프로그램으로, 새 탭 페이지를 사용자 지정 가능한 대시보드로 바꿉니다. 검색, 여러 북마크 화면, 배경을 제공합니다.

## 기능

- 검색 엔진을 선택할 수 있는 검색. 목록은 편집할 수 있습니다.
- 여러 북마크 화면: 점, 빈 영역 스와이프, `Alt+←/→`로 전환.
- 아이콘이 있는 북마크와 드래그 앤 드롭 정렬. 화면 간 이동 지원.
- 배경: URL, 로컬 파일, 단색, 그라데이션.
- 테마(자동/라이트/다크)와 언어(영어/러시아어).
- JSON으로 설정 가져오기 및 내보내기.

## 설치

1. `chrome://extensions` 또는 `edge://extensions`를 엽니다.
2. 개발자 모드를 켭니다.
3. "압축해제된 확장 프로그램을 로드합니다"를 클릭하고 프로젝트 루트를 선택합니다.
4. 새 탭을 엽니다.
