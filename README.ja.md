Chrome と Microsoft Edge 向けの拡張機能で、新しいタブページをカスタマイズ可能なダッシュボードに置き換えます。検索、複数のブックマーク画面、背景を提供します。

## 機能

- 検索エンジンを選択できる検索。リストは編集可能です。
- 複数のブックマーク画面：ドット、空白部分のスワイプ、`Alt+←/→` で切り替え。
- アイコン付きブックマークとドラッグ＆ドロップ並べ替え。画面間の移動も可能。
- 背景：URL、ローカルファイル、単色、グラデーション。
- テーマ（自動/ライト/ダーク）と言語（13 言語）。
- JSON での設定のインポートとエクスポート。

## インストール

1. `chrome://extensions` または `edge://extensions` を開きます。
2. デベロッパーモードを有効にします。
3. 「パッケージ化されていない拡張機能を読み込む」をクリックし、プロジェクトのルートを選択します。
4. 新しいタブを開きます。
