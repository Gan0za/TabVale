适用于 Chrome 和 Microsoft Edge 的扩展，用可自定义的仪表板替换新标签页：搜索、多个书签屏幕和背景。

## 功能

- 可选择搜索引擎的搜索；列表可编辑。
- 多个书签屏幕：通过圆点、在空白处滑动和 `Alt+←/→` 切换。
- 带图标的书签，支持拖放排序；可在屏幕之间移动。
- 背景：URL、本地文件、纯色或渐变。
- 主题（自动/浅色/深色）和 13 种界面语言。
- 以 JSON 导入和导出设置。

## 安装

1. 打开 `chrome://extensions` 或 `edge://extensions`。
2. 启用开发者模式。
3. 点击“加载已解压的扩展程序”，选择项目根目录。
4. 打开新标签页。
