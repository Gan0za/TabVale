Розширення для Chrome і Microsoft Edge, яке замінює сторінку нової вкладки
налаштовуваним робочим столом: пошук, кілька екранів закладок і фони.

## Можливості

- Пошук із вибором пошукової системи; список редагується.
- Кілька екранів закладок: перемикання точками, свайпом порожнім місцем і
  `Alt+←/→`.
- Закладки з іконками та сортуванням перетягуванням; перенесення між
  екранами.
- Фони: посилання, файл із пристрою, колір або градієнт.
- Теми (авто/світла/темна) і 13 мов інтерфейсу.
- Імпорт та експорт налаштувань у JSON.

## Встановлення

1. Відкрийте `chrome://extensions` або `edge://extensions`.
2. Увімкніть режим розробника.
3. Натисніть «Завантажити розпаковане» і виберіть корінь проєкту.
4. Відкрийте нову вкладку.
