# Политика конфиденциальности — TabVale

_Последнее обновление: 2026-11-09_

## Суть в одном абзаце

Расширение **TabVale** не собирает, не обрабатывает и не передаёт
никакие личные данные. Настройки (закладки, экраны, фоны, поисковые системы,
тема, язык) хранятся только в вашем браузере через `chrome.storage.sync`
и `chrome.storage.local`. Если вы вошли в аккаунт браузера, `sync`-данные
синхронизируются им между вашими устройствами. Наружу ничего не уходит.

## Какие данные хранятся и где

| Данные | Где хранится | Куда передаётся |
|---|---|---|
| Закладки (название, адрес, иконка) | `chrome.storage.sync` | Никуда. Синхронизация браузера — только между вашими устройствами |
| Экраны (название, порядок, привязка закладок) | `chrome.storage.sync` | Никуда |
| Активный экран | `chrome.storage.local` | Никуда; у каждого устройства свой |
| Фоны: ссылка, цвет или градиент | `chrome.storage.sync` | Никуда |
| Фоны: файл с устройства (данные изображения) | `chrome.storage.local` | Никуда |
| Поисковые системы (название, адрес, логотип) | `chrome.storage.sync` | Никуда |
| Тема оформления и выбранный язык | `chrome.storage.sync` | Никуда |

## Разрешения расширения

- **storage** — сохранить закладки, экраны, фоны и настройки.
- **unlimitedStorage** — хранить файлы фонов в `chrome.storage.local`;
  без него большое изображение могло не поместиться в квоту.
- **contextMenus** — пункты контекстного меню иконки расширения
  (например, «Настройки»).
- **clipboardRead** — пункты «Вставить», «Вставить и искать» и
  «Вставить и создать» в контекстном меню поля поиска и пустой секции
  закладок. Буфер читается один раз при открытии меню и только по вашему
  действию (правый клик или долгое нажатие). Фонового чтения буфера нет.
- **optional host permissions** — запрашиваются точечно, только когда вы
  добавляете закладку и расширение пытается прочитать `<title>` страницы,
  чтобы предложить название. Браузер показывает запрос; вы можете отказать,
  тогда будет использован только hostname.

## Сетевая активность

Расширение не имеет собственного сервера и не отправляет данные ни на
какие серверы. Иконки сайтов и фоновые изображения загружаются браузером
напрямую с адресов, которые вы указали сами. При добавлении закладки
расширение может запросить у браузера доступ к конкретному сайту, чтобы
прочитать его `<title>`; без вашего разрешения запрос не выполняется.

## Экспорт и удаление данных

- **Экспорт**: в настройках есть кнопка «Экспорт (JSON)» — файл с вашими
  данными сохраняется на диск по вашему желанию. Файлы фонов включаются
  в экспорт.
- **Удаление**: удаление расширения удаляет данные из
  `chrome.storage.sync` и `chrome.storage.local`. Дополнительно чистить
  ничего не нужно.
