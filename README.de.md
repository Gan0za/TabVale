Eine Chrome- und Microsoft-Edge-Erweiterung, die die neue Tab-Seite durch ein
anpassbares Dashboard ersetzt: Suche, mehrere Lesezeichen-Bildschirme und
Hintergründe.

## Funktionen

- Suche mit auswählbarer Suchmaschine; die Liste ist bearbeitbar.
- Mehrere Lesezeichen-Bildschirme: Wechsel per Punkten, Wischen auf freier
  Fläche und `Alt+←/→`.
- Lesezeichen mit Symbolen und Drag-and-drop-Sortierung; Verschieben zwischen
  Bildschirmen.
- Hintergründe: URL, lokale Datei, Farbe oder Verlauf.
- Designs (automatisch/hell/dunkel) und Sprachen (Englisch/Russisch).
- Import und Export der Einstellungen als JSON.

## Installation

1. `chrome://extensions` oder `edge://extensions` öffnen.
2. Den Entwicklermodus aktivieren.
3. „Entpackte Erweiterung laden“ wählen und den Projektordner auswählen.
4. Einen neuen Tab öffnen.
