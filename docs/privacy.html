Privacy Policy

Last updated: 2026-11-09

TabVale does not collect, process or transmit personal data. Settings and user content stay in the browser through chrome.storage.sync and chrome.storage.local. If the user is signed in to the browser, sync data is synchronized by the browser between that user's devices. Nothing is sent to our servers.

Permissions

  • storage — save bookmarks, screens, backgrounds and settings.
  • unlimitedStorage — keep local background image files in chrome.storage.local.
  • contextMenus — add items to the extension icon menu.
  • clipboardRead — paste actions in the custom context menu. The clipboard is read once when that menu is opened on the extension's own new tab page, after an explicit user action. There is no background clipboard access.
  • optional host permissions — requested per site only when adding a bookmark, to read the page <title> as a suggested name. The user can deny the request; the extension then uses the hostname.

Network activity

The extension has no server and does not send data anywhere. Site icons and background images are loaded by the browser from addresses the user entered. When adding a bookmark, the extension may ask the browser for access to that specific site to read its title; without permission the request is not made.

Export and deletion

  • Export — the settings modal can save a JSON file with the user's data, including background files.
  • Deletion — uninstalling the extension removes data from chrome.storage.sync and chrome.storage.local.
