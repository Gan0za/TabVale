# TabVale plugins — план и статус

Рабочая ветка: `feature/plugins` (от master). Master и теги не трогаются до ручного теста.
Версия 1.2.0 живёт только в ветке; после приёмки — мерж и тег через release-workflow.

## Принятые решения

- Хранение: метаданные экранов одним ключом, закладки ключом на экран, крупные экраны — в `storage.local` с фолбэком по квоте; запись сериализована.
- Плагины: манифест + пакет; код в IndexedDB; исполнение только в sandbox-странице через `new Function`; сеть и данные — только через брокер хоста.
- Права: как в VS Code — экран установки показывает запросы манифеста; при расширении прав — повторное согласие (ещё не реализовано).
- Локализация: хост передаёт язык, плагин локализует себя; имя/описание в манифесте — с локалями.
- Фон: опционален. Минимум Chrome остаётся 107; при наличии `chrome.offscreen` (109+) фоновые функции включаются, иначе плагин работает только в открытой вкладке.
- Зоны: `tiles`, `strip` (сверху/снизу), `panel` (сторона/размер/режим), `floating`, `rail`.
- Магазин: встроенный каталог + установка из файла; автозагрузки кода из сети нет.

## Как проверять

```bash
cd self_tabs
for f in tests/*.test.mjs; do node "$f" || exit 1; done
node tools/e2e/plugin-smoke.mjs   # нужен установленный Chrome; окно off-screen
bash package.sh
```

Smoke использует CDP `Extensions.loadUnpacked`, потому что свежий Chrome игнорирует `--load-extension`.

## Автономный цикл

- Один запуск — один связный срез и не более одного коммита; слишком широкий срез запрещён.
- Маркер завершения: `C:\Users\verev\projects\.aicoder\state\plugin-work-complete.md` — код больше не меняется.
- Маркер блокировки: `C:\Users\verev\projects\.aicoder\state\plugin-work-blocked.md` — при его наличии цикл просыпается, но ничего не делает и не повторяет ошибку.
- Запрещено: merge, push, теги, изменения master, упоминания ИИ в сообщениях коммитов.
- Каждый запуск: тесты, при изменениях UI — `tools/e2e/plugin-smoke.mjs`; при падении — фикс или откат шага до коммита.
- Блокировка: откатить частичные правки, записать причину в этот файл и в маркер блокировки, остановиться.
