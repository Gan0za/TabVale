Расширение для Chrome и Microsoft Edge, заменяющее страницу новой вкладки
настраиваемым рабочим столом: поиск, несколько экранов закладок, фоны и
необязательные плагины.

## Возможности

- Поиск с выбором поисковой системы; список движков редактируется, у каждого своя иконка.
- Несколько экранов закладок: точки, свайп по пустому месту, `Alt+←/→`; перенос закладок между экранами.
- Закладки с иконками (кэшируются локально), сортировка перетаскиванием, правка и удаление.
- Фоны: ссылка, файл с устройства, цвет или градиент.
- Темы авто/светлая/тёмная и 13 языков интерфейса.
- Плагины — только те, что вы установили сами: часы, заметки, конвертер раскладок, таймер, пароли, погода, статистика GitHub, запуск приложений, RSS, задачи, импорт закладок.
- Импорт и экспорт настроек в JSON.

## Установка

1. Откройте `chrome://extensions` или `edge://extensions`.
2. Включите режим разработчика.
3. Нажмите «Загрузить распакованное» и выберите корень проекта.
4. Откройте новую вкладку.

## Плагины

Плагинов по умолчанию нет. Готовые пакеты `.tvp` лежат в
[разделе «Плагины» на сайте](https://gan0za.github.io/TabVale/#plugins) и в
папке `docs/plugins/` репозитория. Скачайте файл и установите его:
Настройки → Плагины → «Установить из файла…». Менеджер задаёт зону — панель,
полоса над или под закладками, плитка, плавающее окно; контекстное меню
плагина открывает его строку, выключает или удаляет.

## Разработка плагинов (кратко)

Плагин — zip-пакет `.tvp` с `manifest.json`, файлом кода и необязательной
иконкой. Код определяет `mount(api)` и исполняется в sandbox без `chrome.*`:
данные — `api.storage`, сеть — `api.fetch` по allowlist из манифеста,
интерфейс — `api.ui`, иконки сайтов — `api.icon.favicon`.
Сборка: `node tools/pack-plugin.mjs path/to/plugin`.

Подробности на английском: [формат пакета](docs/PLUGIN_SPEC.md),
[API](docs/PLUGIN_API.md), [руководство](docs/PLUGIN_GUIDE.md).

## Приватность и разрешения

Закладки, экраны, фоны и настройки хранятся в `chrome.storage`; иконки сайтов —
в локальном IndexedDB и не покидают устройство. Подробнее: [PRIVACY.md](PRIVACY.md)
(на английском).
