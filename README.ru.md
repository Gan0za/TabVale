Расширение для Chrome и Microsoft Edge, заменяющее страницу новой вкладки
настраиваемым рабочим столом: поиск, несколько экранов закладок и фоны.

## Возможности

- Поиск с выбором поисковой системы; список движков редактируется.
- Несколько экранов закладок: переключение точками, свайпом по пустому месту
  и `Alt+←/→`.
- Закладки с иконками и сортировкой перетаскиванием; перенос между экранами.
- Фоны: ссылка, файл с устройства, цвет или градиент.
- Темы (авто/светлая/тёмная) и языки (английский/русский).
- Импорт и экспорт настроек в JSON.

## Установка

1. Откройте `chrome://extensions` или `edge://extensions`.
2. Включите режим разработчика.
3. Нажмите «Загрузить распакованное» и выберите корень проекта.
4. Откройте новую вкладку.
