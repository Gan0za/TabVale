Extensión para Chrome y Microsoft Edge que sustituye la página de nueva
pestaña por un panel personalizable: búsqueda, varias pantallas de marcadores
y fondos.

## Funciones

- Búsqueda con motor seleccionable; la lista es editable.
- Varias pantallas de marcadores: cambio con puntos, deslizamiento en una zona
  vacía y `Alt+←/→`.
- Marcadores con iconos y ordenación arrastrando; movimiento entre pantallas.
- Fondos: URL, archivo local, color o degradado.
- Temas (automático/claro/oscuro) e idiomas de la interfaz (13).
- Importación y exportación de ajustes en JSON.

## Instalación

1. Abrir `chrome://extensions` o `edge://extensions`.
2. Activar el modo de desarrollador.
3. Pulsar «Cargar descomprimida» y elegir la raíz del proyecto.
4. Abrir una nueva pestaña.
